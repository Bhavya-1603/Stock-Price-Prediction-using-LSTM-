# 📈 Stock Price Prediction Web App

A simple deep learning-based stock price prediction web application built using Flask, TensorFlow/Keras, and Yahoo Finance data.

The project uses an LSTM model to analyze historical stock prices and visualize:

- Closing Price Trends
- EMA (20, 50, 100, 200)
- Predicted vs Actual Prices

---

# 🚀 Technologies Used

- Python
- Flask
- TensorFlow / Keras
- Pandas & NumPy
- Matplotlib
- yfinance
- Scikit-learn
